## Durable intake fences

Schema v13 adds original-execution non-acceptance proofs and irreversible intake fences. Identity
lookup and fencing serialize in one writer transaction; accepted/completed history is retained.
An empty new incarnation cannot stand in for the old ledger, while a persisted original proof
survives restart. Older binaries reject this schema instead of ignoring fences after downgrade.
The proof manufactures neither Cloud business settlement nor an ordinary execution terminal.
